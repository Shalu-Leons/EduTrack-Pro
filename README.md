# EduTrack Pro

## 📌 Project Overview

EduTrack Pro is a Java-based Student Information Management System that helps manage student records efficiently.

## 🚀 Features

- Student CRUD Operations
- File Handling
- Attendance Management
- Academic Reports
- Search Functionality
- Exception Handling

## 🛠 Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Exception Handling
