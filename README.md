# EduTrack Pro

## 📌 Project Overview

EduTrack Pro is a Java-based Student Information Management System that helps manage student records efficiently.

## 🚀 Features

- Student CRUD Operations
- File Handling
- Attendance Management
- Academic Reports
- Search Functionality
- Exception Handling

# Implemented StudentManager

- Added viewStudents() method


## Implemented menu-driven Add Student

- Displayed all students using View Students
